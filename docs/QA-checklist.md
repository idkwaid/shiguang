# 真机验收清单（QA Checklist）

> 环境没有模拟器/真机，以下步骤需要在 Android 8.0+ 设备上手动走一遍。
> 安装：`adb install -r app/build/outputs/apk/debug/app-debug.apk`

## 0. 安装与启动

- [ ] 安装成功，图标（拾光）与名称正常。
- [ ] 冷启动进入首页，无崩溃；底部 4 个页签可切换。
- [ ] 深色模式下界面可读。

## 1. 导入与图库

- [ ] 首页「添加文件夹」→ 系统目录选择器 → 选 `Pictures` 下某个相册 → 卡片出现、进度条走完后显示张数。
- [ ] 再次添加同一文件夹 → 提示“已经在图库里”。
- [ ] 空文件夹 → “这个文件夹还是空的”。
- [ ] 选中一个**只有压缩包**的文件夹 → 选「分组导入」→ 每个 zip 各成一个图库，能打开出图。
- [ ] 选中一个**多级子目录**的文件夹 → 选「分组导入」→ 每个含图片的目录各成一个图库（名字是相对路径）。
- [ ] 同一文件夹改用「整体导入」→ 仍是一个图库、子目录图片平铺。
- [ ] 旧版本升级安装后，原有图库仍在（迁移不清库）；打开后缩略图自动重建。
- [ ] 导入 ZIP：文件名排序正确（1,2,10 而非 1,10,2），子目录图片平铺显示。
- [ ] 导入 RAR：能打开；首次读取较慢属正常（复制到缓存）。
- [ ] 导入 7Z：能打开。
- [ ] 加密 ZIP/RAR/7Z → 弹出密码框；错误密码提示；正确密码后正常出图。
- [ ] 损坏压缩包（改扩展名的文本文件）→ “压缩包已损坏/读取失败”，不崩溃。
- [ ] 图库长按 → 重新扫描 / 重命名 / 设为私密 / 从图库移除；移除后源文件仍存在。

## 2. 浏览与全屏

- [ ] 打开图库 → 两列瀑布流，缩略图逐渐出现。
- [ ] 点图片 → 全屏黑底、状态栏隐藏、页码 “n / N”。
- [ ] 左右滑动翻页；页码同步。
- [ ] 双指捏合放大、拖拽看局部；放大后翻页不会误触。
- [ ] 双击放大/还原；单击隐藏/显示上下 UI。
- [ ] 双指长按 → 回到原图大小并显示“原图”，松手恢复。
- [ ] 屏幕左边缘右滑 → 返回图库；下拉 → 返回图库。
- [ ] 点页码 → 缩略图面板；点任意缩略图跳转。
- [ ] 打开一张正常 JPEG：缩略图和全屏都能显示（v0.2.0 修复点）。
- [ ] 人为放一个损坏图片：全屏显示“无法解码”并可点「重试」，不无限转圈；网格显示破图图标。
- [ ] 退出后重进图库 → 顶部出现“继续浏览 · 第 N 张”。
- [ ] 幻灯片 → 每 3 秒自动翻页；点暂停停止。
- [ ] 上下滑动状态栏区域，系统栏可临时呼出。

## 3. 收藏 / 标签 / 探索

- [ ] 全屏点收藏 → 收藏页出现该图（跨图库）。
- [ ] 再从系统删除该源文件 → 图库刷新后，收藏页显示灰色占位。
- [ ] 收藏页右上“清理失效收藏” → 占位数减少。
- [ ] 图库长按图片 → 标签 → 新建“壁纸”并勾选；探索 → 标签聚合 → 能看到该图。
- [ ] 探索 → 那年今日：有历史照片时按年份分组；无照片时为空状态。
- [ ] 探索 → 随机回忆：抽 60 张；换一批不同。
- [ ] 全局搜索：输入图库名/文件名（中文、数字）能命中；输入 `%`/`_` 不崩。

## 4. 信息与工具

- [ ] 全屏 → 信息：显示相机、ISO、光圈、快门、焦距、GPS（若照片有）、大小、路径。
- [ ] 探索 → 智能清理 → 重复：点“保留第一张，删除其余”能删除源文件（确认弹窗提示不可恢复）。
- [ ] 相似：连拍/近似图能归组。
- [ ] 格式：GIF/HEIC 列表 → 删除。
- [ ] 全屏 → 编辑：旋转、翻转、选 1:1、输入水印、写备注 → 保存副本 → 系统相册 `Pictures/拾光` 出现新图，原图未变。
- [ ] 图库长按 → 分享 → 系统分享面板可发出图片。
- [ ] 压缩包里的图点删除 → 提示只移出索引，压缩包文件不变。

## 5. 隐私与安全

- [ ] 设置 → 私密空间 → 设置 4 位密码。
- [ ] 首页长按图库 → 设为私密 → 该图库从首页消失，右上出现锁图标。
- [ ] 点锁图标 → 私密空间：输入密码进入，列出私密图库。
- [ ] 杀进程/退后台再回来 → 私密空间已上锁。
- [ ] 开启指纹/面容 → 进入私密空间时自动弹生物识别；取消后可改用密码。
- [ ] 在私密图库或全屏查看私密图时截屏 → 相册里是黑屏/无法截屏；普通图库截屏正常。
- [ ] 最近任务列表不显示私密页内容（API 33+）。

## 6. 性能与稳定

- [ ] 1000+ 张文件夹：首次扫描可接受（< 10s，视设备），滚动流畅。
- [ ] 切后台 / 锁屏 / 旋转屏幕 / 分屏不崩溃。
- [ ] 断网无影响（App 不联网）。
- [ ] 清除缓存（设置 → 缩略图缓存清空）后图片可重新生成。
- [ ] 图库菜单「重新生成缩略图」能修复空白缩略图。
- [ ] 分组导入几十个图库后，后台扫描/缩略图生成不会卡死 UI。

## 已知不可验收（环境限制）

- 生物识别、FLAG_SECURE、SAF 实际 provider 行为、真实手势手感必须真机；单元测试只能覆盖数据与算法层。
